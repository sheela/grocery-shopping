Which Grocery Deal Is Really Better?

A lower package price does not necessarily mean a better deal. For each pair, choose the option you would buy after checking the shelf label.

How to compare: Look past the big package price and find the unit price in the smaller print. Make sure you are comparing the same unit (per oz, per lb, per 100 ct, etc.). If one label says per ounce and another says per pound, convert them before deciding. Remember: 1 pound = 16 ounces. Package size can be deceptive!
